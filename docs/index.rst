TI-84 Evo for PyCharm
=====================

TI-84 Evo for PyCharm is a native Kotlin IntelliJ Platform plugin for
communicating with the TI-84 Evo over its CDC serial interface.

This is an alpha hardware-integration project. The protocol implementation
and host-side tests are included in the repository, while acceptance on a
physical calculator remains a separate hardware test.
